    注意力模块的张量表示及梯度推导¶

    自注意力¶

    代码部分

    import torch 
import torch.nn as nn 
class SelfAttention(nn.Module): 
def __init__(self, d_in, d_out, qkv_bias=False): 
    self.W_q = nn.Linear(d_in, d_out, bias=qkv_bias) 
    self.W_k = nn.Linear(d_in, d_out, bias=qkv_bias) 
    self.W_v = nn.Linear(d_in, d_out, bias=qkv_bias) 
def forward(self, x): 
    q = self.W_q(x) 
    k = self.W_k(x) 
    v = self.W_v(x) 
    attn_scores = torch.matmul(q, k.T) 
    attn_weights = torch.softmax(attn_scores / k.shape[-1] ** 0.5, dim=-1)
    context_vecs = torch.matmul(attn_weights, v) 
    return context_vecs

    前向过程¶

    索引和张量定义

    • \(t_1, t_2\) : Token/序列 (Sequence) 索引。 \(t_1\) 代表查询 (Query)， \(t_2\) 代表键/值 (Key/Value)。
    • \(i, k\) : 输入特征维度 ( \(d\_in\) ) 的索引。
    • \(j\) : 输出/内部特征维度 ( \(d\_out\) ) 的索引。 输入张量：
    • Input \(X\) : \(X_{ti}\) (对应代码中的 x)
    • Query Weights \(W_Q\) : \(W^Q_{ji}\) (对应 self.W_q.weight)
    • Key Weights \(W_K\) : \(W^K_{jk}\) (对应 self.W_k.weight)
    • Value Weights \(W_V\) : \(W^V_{jk}\) (对应 self.W_v.weight)
    • Output \(Y\) : \(Y_{t_1 j}\) (对应 context_vecs)
    1. q, k, v 的计算 (线性) 这是输入 \(X\) 和权重矩阵之间的张量缩并（矩阵乘法）。
    2. Query: \(Q_{t_1 j} = X_{t_1 i} W^Q_{ji}\)
    3. Key: \(K_{t_2 j} = X_{t_2 k} W^K_{jk}\)
    4. Value: \(V_{t_2 j} = X_{t_2 k} W^V_{jk}\) （在爱因斯坦约定中，重复的索引 \(i\) 和 \(k\) 表示在 \(d\_in\) 维度上求和。）
    5. attn_scores 的计算 (线性) attn_scores = torch.matmul(q, k.T)。这是一个矩阵乘法，它在 \(j\) (即 \(d\_out\) ) 维度上进行缩并。 \(\displaystyle S_{t_1 t_2} = Q_{t_1 j} K_{t_2 j}\)
    6. attn_weights 的计算 (非线性) attn_weights = torch.softmax(...)。这一步是**非线性的**，不能用简单的张量缩并表示。我们将其定义为函数 \(A = \text{softmax}(S')\) ： \(\displaystyle S'_{t_1 t_2} = S_{t_1 t_2} / \sqrt{d_{out}}\) \(\displaystyle A_{t_1 t_2} = \frac{\exp(S'_{t_1 t_2})}{\mathbf{1}_{t_2'} \exp(S'_{t_1 t_2'})}\) \(A_{t_1 t_2}\) 是最终的注意力权重矩阵。
    7. context_vecs 的计算 (线性) context_vecs = torch.matmul(attn_weights, v)。这是注意力权重 \(A\) 和值 \(V\) 之间的矩阵乘法。它在 \(t_2\) 维度（序列）上进行缩并： \(\displaystyle Y_{t_1 j} = A_{t_1 t_2} V_{t_2 j}\)

    总结：组合的张量形式 我们可以把这些步骤代入，得到一个更完整的（但分步的）张量表示：

    1. 计算分数 (Scores): \(\displaystyle S_{t_1 t_2} = (X_{t_1 i} W^Q_{ji}) (X_{t_2 k} W^K_{jk})\)
    2. 应用非线性 (Softmax): \(\displaystyle A_{t_1 t_2} = \text{softmax}\left( \frac{S_{t_1 t_2}}{\sqrt{d_{out}}} \right)\)
    3. 计算上下文 (Context): \(\displaystyle Y_{t_1 j} = A_{t_1 t_2} (X_{t_2 k} W^V_{jk})\)

    最终的输出 \(Y_{t_1 j}\) 是**所有 \(t_2\) 位置的值**（经过 \(W^V\) 变换后）的**动态加权和**，权重 \(A_{t_1 t_2}\) 是根据查询和键（ \(X\) 和 \(W^Q, W^K\) ）动态计算出来的。

    梯度推导¶

    引言和符号定义¶

    我们假设我们已经拥有了损失 \(L\) 相对于注意力层最终输出 \(Y\) 的梯度。我们将其定义为 \(G^Y\) ：

    \[G^Y_{t_1 j} = \frac{\partial L}{\partial Y_{t_1 j}}\]

    目标：

    我们希望求解以下三个梯度：

    1. \(\frac{\partial L}{\partial W^V_{jk}}\) (Value 权重)
    2. \(\frac{\partial L}{\partial W^Q_{ji}}\) (Query 权重)
    3. \(\frac{\partial L}{\partial W^K_{jk}}\) (Key 权重)

    中间梯度符号：

    为了使推导更清晰，我们定义 \(G^Z = \frac{\partial L}{\partial Z}\) ，表示 \(L\) 对任意中间张量 \(Z\) 的梯度。

    第 1 部分： \(W^V\) (Value) 的梯度推导¶

    此路径不经过 Softmax，最为直接。

    反向传播路径是： \(L \rightarrow Y \rightarrow V \rightarrow W^V\) 。

    步骤 1.1：计算 \(\frac{\partial L}{\partial V}\) (即 \(G^V\) )

    • 前向方程： \(Y_{t_1 j} = A_{t_1 t_2} V_{t_2 j}\)
    • 应用链式法则： 我们对一个特定的 \(V_{t_2 j}\) 求导：

    \(\displaystyle G^V_{t_2 j} = \frac{\partial L}{\partial V_{t_2 j}} = \sum_{t_1'} \sum_{j'} \frac{\partial L}{\partial Y_{t_1' j'}} \frac{\partial Y_{t_1' j'}}{\partial V_{t_2 j}}\) - 计算局部梯度： \(\frac{\partial Y_{t_1' j'}}{\partial V_{t_2 j}} = \frac{\partial (A_{t_1' t_2'} V_{t_2' j'})}{\partial V_{t_2 j}} = A_{t_1' t_2} \delta_{j' j}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle G^V_{t_2 j} = G^Y_{t_1 j} A_{t_1 t_2}\)

    步骤 1.2：计算 \(\frac{\partial L}{\partial W^V}\)

    • 前向方程： \(V_{t_2 j} = X_{t_2 k} W^V_{jk}\)
    • 应用链式法则：

    \(\displaystyle \frac{\partial L}{\partial W^V_{jk}} = \sum_{t_2'} \sum_{j'} \frac{\partial L}{\partial V_{t_2' j'}} \frac{\partial V_{t_2' j'}}{\partial W^V_{jk}}\) - 计算局部梯度： \(\frac{\partial V_{t_2' j'}}{\partial W^V_{jk}} = \frac{\partial (X_{t_2' k'} W^V_{j' k'})}{\partial W^V_{jk}} = X_{t_2' k} \delta_{j' j}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle \frac{\partial L}{\partial W^V_{jk}} = G^V_{t_2 j} X_{t_2 k}\)

    \(W^V\) 梯度总结¶

    将步骤 1.1 代入 1.2，得到 \(W^V\) 的最终梯度：

    \[\frac{\partial L}{\partial W^V_{jk}} = (G^Y_{t_1 j} A_{t_1 t_2}) X_{t_2 k}\]

    第 2 部分： \(W^Q\) (Query) 和 \(W^K\) (Key) 的梯度推导¶

    此路径是 \(L \rightarrow Y \rightarrow A \rightarrow S' \rightarrow S \rightarrow \{Q, K\} \rightarrow \{W^Q, W^K\}\) 。

    步骤 2.1：计算 \(\frac{\partial L}{\partial A}\) (即 \(G^A\) )

    • 前向方程： \(Y_{t_1 j} = A_{t_1 t_2} V_{t_2 j}\)
    • 应用链式法则：

    \(\displaystyle G^A_{t_1 t_2} = \frac{\partial L}{\partial A_{t_1 t_2}} = \sum_{t_1'} \sum_{j'} \frac{\partial L}{\partial Y_{t_1' j'}} \frac{\partial Y_{t_1' j'}}{\partial A_{t_1 t_2}}\) - 计算局部梯度： \(\frac{\partial Y_{t_1' j'}}{\partial A_{t_1 t_2}} = \frac{\partial (A_{t_1' t_2'} V_{t_2' j'})}{\partial A_{t_1 t_2}} = \delta_{t_1' t_1} V_{t_2 j'}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle G^A_{t_1 t_2} = G^Y_{t_1 j} V_{t_2 j}\)

    步骤 2.2：计算 \(\frac{\partial L}{\partial S}\) (即 \(G^S\) )

    这是最关键的步骤： \(L \rightarrow A \rightarrow S' \rightarrow S\) 。

    • 前向方程：

    • \(S'_{t_1 t_2} = S_{t_1 t_2} / \sqrt{d_{out}}\)

    • \(A_{t_1 t_2} = \frac{\exp(S'_{t_1 t_2})}{\sum_{t_2''} \exp(S'_{t_1 t_2''})}\) (Softmax)
    • 应用链式法则：

    我们想求 \(\frac{\partial L}{\partial S_{t_1 t_2}}\) (一个特定的 \(S\) 元素)。 \(S_{t_1 t_2}\) 通过 \(S_{t_1 t_2}'\) 影响第 \(t_1\) 行的所有 \(A\) 元素（即 \(A_{t_1 t_2'}\) ，其中 \(t_2'\) 是该行的任一列）。

    \(\displaystyle G^S_{t_1 t_2} = \frac{\partial L}{\partial S_{t_1 t_2}} = \sum_{t_2'} \frac{\partial L}{\partial A_{t_1 t_2'}} \frac{\partial A_{t_1 t_2'}}{\partial S_{t_1 t_2}}\)

    (注意：Softmax 是逐行应用的，所以 \(S_{t_1 t_2}\) 只影响 \(A_{t_1 :}\) ，这就是为什么求和中没有 \(t_1'\) 。) - 计算局部梯度（ \(\frac{\partial A_{t_1 t_2'}}{\partial S_{t_1 t_2}}\) ）：

    我们需要再次使用链式法则：

    \(\displaystyle \frac{\partial A_{t_1 t_2'}}{\partial S_{t_1 t_2}} = \sum_{t_2''} \frac{\partial A_{t_1 t_2'}}{\partial S'_{t_1 t_2''}}\frac{\partial S'_{t_1 t_2''}}{\partial S_{t_1 t_2}}\) 1. 缩放梯度： \(\frac{\partial S'_{t_1 t_2''}}{\partial S_{t_1 t_2}} = \frac{\partial (S_{t_1 t_2''} / \sqrt{d_{out}})}{\partial S_{t_1 t_2}} = \frac{1}{\sqrt{d_{out}}} \delta_{t_2'' t_2}\) 2. Softmax 雅可比矩阵： \(\frac{\partial A_{t_1 t_2'}}{\partial S'_{t_1 t_2''}}\)

    Case 1: \(t_2' = t_2''\) (对角线元素)

    Case 2: \(t_2' \neq t_2''\) (非对角线元素)

    组合 (Kronecker Delta): \(\frac{\partial A_{t_1 t_2'}}{\partial S'_{t_1 t_2''}} = A_{t_1 t_2'} (\delta_{t_2' t_2''} - A_{t_1 t_2''})\) 3. 代回 (1) 和 (2) 到局部梯度：

    \(\displaystyle \frac{\partial A_{t_1 t_2'}}{\partial S_{t_1 t_2}} = \sum_{t_2''} \left[ A_{t_1 t_2'} (\delta_{t_2' t_2''} - A_{t_1 t_2''}) \right] \left[ \frac{1}{\sqrt{d_{out}}} \delta_{t_2'' t_2} \right]\)

    由于 \(\delta_{t_2'' t_2}\) ， \(t_2''\) 上的求和坍缩，我们只需令 \(t_2'' = t_2\) :

    \(\displaystyle \frac{\partial A_{t_1 t_2'}}{\partial S_{t_1 t_2}} = \frac{1}{\sqrt{d_{out}}} A_{t_1 t_2'} (\delta_{t_2' t_2} - A_{t_1 t_2})\) - 代回 \(G^S\) 的推导：

    \(\displaystyle G^S_{t_1 t_2} = \sum_{t_2'} G^A_{t_1 t_2'} \left[ \frac{1}{\sqrt{d_{out}}} A_{t_1 t_2'} (\delta_{t_2' t_2} - A_{t_1 t_2}) \right]\) \(\displaystyle G^S_{t_1 t_2} = \frac{1}{\sqrt{d_{out}}} \sum_{t_2'} \left( G^A_{t_1 t_2'} A_{t_1 t_2'} \delta_{t_2' t_2} - G^A_{t_1 t_2'} A_{t_1 t_2'} A_{t_1 t_2} \right)\) - 拆分求和：

    1. \(\sum_{t_2'} G^A_{t_1 t_2'} A_{t_1 t_2'} \delta_{t_2' t_2}\) = (由于 \(\delta_{t_2' t_2}\) ， \(t_2'\) 上的求和坍缩) = \(G^A_{t_1 t_2} A_{t_1 t_2}\)
    2. \(\sum_{t_2'} G^A_{t_1 t_2'} A_{t_1 t_2'} A_{t_1 t_2} = A_{t_1 t_2} \sum_{t_2'} G^A_{t_1 t_2'} A_{t_1 t_2'}\)
    3. 组合：

    \(\displaystyle G^S_{t_1 t_2} = \frac{1}{\sqrt{d_{out}}} \left( G^A_{t_1 t_2} A_{t_1 t_2} - A_{t_1 t_2} \sum_{t_2'} G^A_{t_1 t_2'} A_{t_1 t_2'} \right)\) \(\displaystyle G^S_{t_1 t_2} = \frac{A_{t_1 t_2}}{\sqrt{d_{out}}} \left( G^A_{t_1 t_2} - \sum_{t_2'} G^A_{t_1 t_2'} A_{t_1 t_2'} \right)\) - 用爱因斯坦约定表示：

    \(\displaystyle G^S_{t_1 t_2} = \frac{A_{t_1 t_2}}{\sqrt{d_{out}}} (G^A_{t_1 t_2} - G^A_{t_1 t_2'} A_{t_1 t_2'})\)

    (其中 \(t_2'\) 是在 \(G^A\) 和 \(A\) 的逐元素乘积上求和的哑索引。)

    步骤 2.3：计算 \(\frac{\partial L}{\partial Q}\) (即 \(G^Q\) )

    • 前向方程： \(S_{t_1 t_2} = Q_{t_1 j} K_{t_2 j}\)
    • 应用链式法则： (现在我们使用 \(G^S\) 作为上游梯度)

    \(\displaystyle G^Q_{t_1 j} = \frac{\partial L}{\partial Q_{t_1 j}} = \sum_{t_1'} \sum_{t_2'} \frac{\partial L}{\partial S_{t_1' t_2'}} \frac{\partial S_{t_1' t_2'}}{\partial Q_{t_1 j}}\) - 计算局部梯度： \(\frac{\partial S_{t_1' t_2'}}{\partial Q_{t_1 j}} = \frac{\partial (Q_{t_1' j'} K_{t_2' j'})}{\partial Q_{t_1 j}} = \delta_{t_1' t_1} K_{t_2' j}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle G^Q_{t_1 j} = G^S_{t_1 t_2} K_{t_2 j}\)

    步骤 2.4：计算 \(\frac{\partial L}{\partial K}\) (即 \(G^K\) )

    • 前向方程： \(S_{t_1 t_2} = Q_{t_1 j} K_{t_2 j}\)
    • 应用链式法则：

    \(\displaystyle G^K_{t_2 j} = \frac{\partial L}{\partial K_{t_2 j}} = \sum_{t_1'} \sum_{t_2'} \frac{\partial L}{\partial S_{t_1' t_2'}} \frac{\partial S_{t_1' t_2'}}{\partial K_{t_2 j}}\) - 计算局部梯度： \(\frac{\partial S_{t_1' t_2'}}{\partial K_{t_2 j}} = \frac{\partial (Q_{t_1' j'} K_{t_2' j'})}{\partial K_{t_2 j}} = Q_{t_1' j'} \delta_{t_2' t_2}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle G^K_{t_2 j} = G^S_{t_1 t_2} Q_{t_1 j}\)

    步骤 2.5：计算 \(\frac{\partial L}{\partial W^Q}\)

    • 前向方程： \(Q_{t_1 j} = X_{t_1 i} W^Q_{ji}\)
    • 应用链式法则：

    \(\displaystyle \frac{\partial L}{\partial W^Q_{ji}} = \sum_{t_1'} \sum_{j'} \frac{\partial L}{\partial Q_{t_1' j'}} \frac{\partial Q_{t_1' j'}}{\partial W^Q_{ji}}\) - 计算局部梯度： \(\frac{\partial Q_{t_1' j'}}{\partial W^Q_{ji}} = \frac{\partial (X_{t_1' i'} W^Q_{j' i'})}{\partial W^Q_{ji}} = X_{t_1' i} \delta_{j' j}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle \frac{\partial L}{\partial W^Q_{ji}} = G^Q_{t_1 j} X_{t_1 i}\)

    步骤 2.6：计算 \(\frac{\partial L}{\partial W^K}\)

    • 前向方程： \(K_{t_2 j} = X_{t_2 k} W^K_{jk}\)
    • 应用链式法则：

    \(\displaystyle \frac{\partial L}{\partial W^K_{jk}} = \sum_{t_2'} \sum_{j'} \frac{\partial L}{\partial K_{t_2' j'}} \frac{\partial K_{t_2' j'}}{\partial W^K_{jk}}\) - 计算局部梯度： \(\frac{\partial K_{t_2' j'}}{\partial W^K_{jk}} = \frac{\partial (X_{t_2' k'} W^K_{j' k'})}{\partial W^K_{jk}} = X_{t_2' k} \delta_{j' j}\) - 代回（并使用爱因斯坦约定）：

    \(\displaystyle \frac{\partial L}{\partial W^K_{jk}} = G^K_{t_2 j} X_{t_2 k}\)

    \(W^Q\) 和 \(W^K\) 梯度总结

    将 2.3 代入 2.5，得到 \(W^Q\) 的最终梯度：

    \[\frac{\partial L}{\partial W^Q_{ji}} = (G^S_{t_1 t_2} K_{t_2 j}) X_{t_1 i}\]

    将 2.4 代入 2.6，得到 \(W^K\) 的最终梯度：

    \[\frac{\partial L}{\partial W^K_{jk}} = (G^S_{t_1 t_2} Q_{t_1 j}) X_{t_2 k}\]

    其中 \(G^S_{t_1 t_2}\) 由**步骤 2.2** 定义。

    最终梯度总结¶

    以下是损失 \(L\) 对三个权重矩阵的完整梯度，其中 \(G^S\) 已被明确推导。

    1. Value 权重梯度 ( \(W^V\) ):

    \(\displaystyle \frac{\partial L}{\partial W^V_{jk}} = \left( \frac{\partial L}{\partial Y_{t_1 j}} A_{t_1 t_2} \right) X_{t_2 k}\)

    公式解释：Value 权重梯度是误差信号和注意力权重在 \(t_{1}\) 上的内积，也就是计算Value在查询token维度上对误差信号有多大贡献，即分配给Value的误差。然后再和输入嵌入在 \(t_{2}\) 上的内积，计算此时被 \(X_{t_{2}k}\) 激活的信号。

    1. Query 权重梯度 ( \(W^Q\) ):

    \(\displaystyle \frac{\partial L}{\partial W^Q_{ji}} = \left( \frac{\partial L}{\partial S_{t_1 t_2}} K_{t_2 j} \right) X_{t_1 i}\)

    公式解释： 2. Key 权重梯度 ( \(W^K\) ):

    \(\displaystyle \frac{\partial L}{\partial W^K_{jk}} = \left( \frac{\partial L}{\partial S_{t_1 t_2}} Q_{t_1 j} \right) X_{t_2 k}\)

    其中，关键的中间梯度 \(\frac{\partial L}{\partial S_{t_1 t_2}}\) (即 \(G^S\) ) 定义为：

    \[\frac{\partial L}{\partial S_{t_1 t_2}} = \frac{A_{t_1 t_2}}{\sqrt{d_{out}}} \left( \frac{\partial L}{\partial A_{t_1 t_2}} - \sum_{t_2'} \frac{\partial L}{\partial A_{t_1 t_2'}} A_{t_1 t_2'} \right)\]

    公式解释: 注意力权重对损失的贡献既要看直接贡献也要看平均贡献。括号内的求和实际上就是求平均贡献，是一个相对标准，它奖励那些表现优于“平均水平”的得分，并惩罚那些表现不如平均水平的得分。

    而 \(\frac{\partial L}{\partial A_{t_1 t_2}}\) (即 \(G^A\) ) 定义为：

    \[\frac{\partial L}{\partial A_{t_1 t_2}} = \frac{\partial L}{\partial Y_{t_1 j}} V_{t_2 j}\]

    代码验证¶

    import torch
import torch.nn as nn
import torch.testing # 导入测试库
# ---------------------------------------------------------------------------
# 步骤 1: 修改 SelfAttention 以存储 q, k, v
# ---------------------------------------------------------------------------
# 我们必须存储 q, k, v 才能在之后访问它们来计算梯度
#
class SelfAttention(nn.Module):
    def __init__(self, d_in, d_out, qkv_bias=False):
        super().__init__()
        self.W_q = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_k = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_v = nn.Linear(d_in, d_out, bias=qkv_bias)
        # 为所有中间张量添加占位符
        self.q = None
        self.k = None
        self.v = None
        self.attn_scores = None  # S
        self.attn_weights = None # A
        self.context_vecs = None # Y

    def forward(self, x):
        # 计算 q, k, v 并 *保存* 它们
        self.q = self.W_q(x)
        self.k = self.W_k(x)
        self.v = self.W_v(x)
        # d_k (d_out) 的缩放因子
        scale = self.k.shape[-1] ** 0.5
        # S = Q @ K.T
        self.attn_scores = torch.matmul(self.q, self.k.transpose(-2, -1))
        # A = softmax(S / scale)
        self.attn_weights = torch.softmax(self.attn_scores / scale, dim=-1)
        # Y = A @ V
        self.context_vecs = torch.matmul(self.attn_weights, self.v)
        return self.context_vecs
# ---------------------------------------------------------------------------
# 步骤 2: 设置并运行前向和后向传播
# ---------------------------------------------------------------------------
# 设置输入维度和输出维度
i,j=10,20
# 创建SelfAttention对象
attention = SelfAttention(d_in=i, d_out=j)
# 为了可复现性，固定随机种子
torch.manual_seed(42)
# 创建输入张量和上游梯度
x = torch.rand((10, 10, 10), requires_grad=True) # (B, S_in, d_in)
y_grad = torch.rand((10, 10, 20)) # (B, S_out, d_out)
# 运行前向和后向过程
# 这会为 W_v.weight, W_q.weight, W_k.weight 自动填充 .grad 属性
y = attention(x)
y.backward(y_grad)
# ---------------------------------------------------------------------------
# 步骤 3: 按照你提供的公式手动计算梯度并进行验证
# ---------------------------------------------------------------------------
print("--- 梯度验证开始 ---")
# 索引约定:
# b: batch (10)
# q: query token 序列 (10)
# v: key/value token 序列 (10)
# i: d_in (10)
# o: d_out (20)
# ---------------------------------
# 3.A: 计算中间梯度 G^A 和 G^S
# ---------------------------------
# G^A = dL/dA
# 公式: dL/dA[q,v] = dL/dY[q,o] * V[v,o]
# einsum: (bqo, bvo) -> bqv
grad_A = torch.einsum('bqo, bvo -> bqv', y_grad, attention.v)
# G^S = dL/dS
# 这是 softmax 的反向传播
# 公式: dL/dS = (A / scale) * (dL/dA - sum(dL/dA * A))
scale = attention.k.shape[-1] ** 0.5
A = attention.attn_weights
# sum(dL/dA * A)
# einsum: (bqv, bqv) -> bq
row_dot_sum = torch.einsum('bqv, bqv -> bq', grad_A, A).unsqueeze(-1) # 形状变为 (b,q,1)
# dL/dS' = A * (dL/dA - sum(dL/dA * A))
# (bqv) * ((bqv) - (bq,1)) -> (bqv)
grad_S_prime = A * (grad_A - row_dot_sum)
# dL/dS = dL/dS' / scale
# (bqv)
grad_S = grad_S_prime / scale
# ---------------------------------
# 3.B: 验证 Value 权重梯度 (W^V)
# ---------------------------------
try:
    # 公式: dL/dW_v[o,i] = (dL/dY[q,o] * A[q,v]) * X[v,i]
    # (注意你的公式中 j->o, k->i, t1->q, t2->v)
    # einsum: (bqo, bqv, bvi) -> oi
    grad_Wv_manual = torch.einsum('bqo, bqv, bvi -> oi',
                                  y_grad,
                                  attention.attn_weights,
                                  x)
    torch.testing.assert_close(grad_Wv_manual, attention.W_v.weight.grad)
    print("W_v 梯度计算正确")
except AssertionError as e:
    print(f"W_v 梯度计算错误:\n{e}")
# ---------------------------------
# 3.C: 验证 Query 权重梯度 (W^Q)
# ---------------------------------
try:
    # 公式: dL/dW_q[o,i] = (dL/dS[q,v] * K[v,o]) * X[q,i]
    # (注意你的公式中 j->o, i->i, t1->q, t2->v)
    # einsum: (bqv, bvo, bqi) -> oi
    grad_Wq_manual = torch.einsum('bqv, bvo, bqi -> oi',
                                  grad_S,
                                  attention.k,
                                  x)
    torch.testing.assert_close(grad_Wq_manual, attention.W_q.weight.grad)
    print("W_q 梯度计算正确")
except AssertionError as e:
    print(f"W_q 梯度计算错误:\n{e}")
# ---------------------------------
# 3.D: 验证 Key 权重梯度 (W^K)
# ---------------------------------
try:
    # 公式: dL/dW_k[o,i] = (dL/dS[q,v] * Q[q,o]) * X[v,i]
    # (注意你的公式中 j->o, k->i, t1->q, t2->v)
    # einsum: (bqv, bqo, bvi) -> oi
    grad_Wk_manual = torch.einsum('bqv, bqo, bvi -> oi',
                                  grad_S,
                                  attention.q,
                                  x)
    torch.testing.assert_close(grad_Wk_manual, attention.W_k.weight.grad)
    print("W_k 梯度计算正确")
except AssertionError as e:
    print(f"W_k 梯度计算错误:\n{e}")
print("--- 梯度验证完成 ---")

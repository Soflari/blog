# 意图：迁移旧 Hugo 博客文章到本站

## 背景

用户在 GitHub 上有旧 Hugo 博客（`Soflari/hugo_dev`，Pages 部署），希望把里面写的文章迁移到现在这个 MkDocs Material 博客。

## 需求

- 迁移文章到 `docs/blog/posts/`，格式转换为本站约定（YAML front matter、正文 `#` 标题、`$...$`/`$$...$$` 公式、图片进 `docs/assets/`）。
- 用户指定范围（2026-09-08 批准时明确）：**只迁 5 篇**——卷积模块的张量表示及梯度推导、mlp的张量表示及梯度推导、注意力模块的张量表示及梯度推导、esl第五章基展开和正则化、深度学习理论笔记。其余 12 篇跳过留档，日后想补可重跑脚本。

## 关键事实

- `hugo_dev` 仓库只有 Hugo 构建产物（渲染后 HTML），无 Markdown 源稿；本机、GitHub 公开面、仓库 git 历史均探测无源稿（探测记录见 checklist.md）。
- 这 5 篇全是数学公式重灾区，公式保真是本次迁移的核心质量风险。

## 约束

- 不给项目加依赖（CI 用 `uv sync --locked` 锁死）；Python 一律 uv。
- push 上线必须用户授权，本次只做到本地 commit。

## 成功标准

strict 构建通过；5 篇全部出现在博客列表且日期正确；公式渲染正常（对拍旧站）；`p/` 全集双向对账无遗漏；checklist 留档完整。

## 分级

L1（单次迁移任务，改动文件数 >3 触发独立复核）。方案经 3 轮轮审 + 2 难点深审 + 2 次链尾终检收敛后用户批准（详见 plan.md 头部评审记录）。
